# Student Marks Predictor

## 1. About the Project

Student Marks Predictor is a beginner-level Machine Learning project developed using Python.

The project predicts a student's expected final marks based on four factors:

- Daily study hours
- Attendance percentage
- Previous examination marks
- Number of assignments completed

The project uses Linear Regression to make the prediction.

---

## 2. Objective

The main objectives of this project are:

1. To understand the basic concepts of Machine Learning.
2. To work with a dataset using Python.
3. To train a Machine Learning model.
4. To predict student marks using the trained model.
5. To evaluate the performance of the model.
6. To create a simple graphical user interface.

---

## 3. Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Tkinter

---

## 4. Machine Learning Algorithm

Linear Regression is used in this project.

Linear Regression is a supervised Machine Learning algorithm used to predict a continuous numerical value.

In this project, the target variable is the student's final marks.

---

## 5. Input Features

The model uses the following features:

1. Study Hours
2. Attendance Percentage
3. Previous Exam Marks
4. Assignments Completed

---

## 6. Target Variable

The target variable is:

Final Marks

---

## 7. Dataset

The project uses a small sample dataset created for educational purposes.

The dataset contains information about study hours, attendance, previous marks, assignments, and final marks.

---

## 8. Working of the Project

The project follows these steps:

1. Load the dataset.
2. Check the dataset.
3. Select input features and target variable.
4. Split the dataset into training and testing data.
5. Train the Linear Regression model.
6. Evaluate the model.
7. Accept student information through the GUI.
8. Predict the expected final marks.
9. Display the predicted marks and performance level.
